# Лабораторная работа №5 — UI-тестирование с Playwright

Для автоматизации используется Python + Playwright.

## Сценарий 1 — авторизованный пользователь

Тест выполняется в обычном Chrome с графическим интерфейсом.

Сценарий:

1. Открыть RUTUBE.
2. Выполнить поиск видео.
3. Открыть первый результат.
4. Проверить состояние кнопки «Нравится».
5. Если лайк уже установлен — снять его и обновить страницу.
6. Поставить лайк.
7. Обновить страницу.
8. Проверить, что лайк сохранился.

Авторизация выполняется вручную в Chrome. Playwright подключается к уже открытому и авторизованному браузеру через Chrome DevTools Protocol (CDP).

Такой подход выбран потому, что автоматическая авторизация через браузер, запущенный Playwright, может блокироваться антифродом.

Изначально рассматривался YouTube, но возникли дополнительные ограничения:
- доступ к YouTube нестабилен;
- headless-браузер может получать антибот-проверку;
- автоматическая авторизация может блокироваться;
- в CI отсутствует пользовательская авторизованная сессия.

## Сценарий 2 — headless

Сценарий выполняется без авторизации в headless-режиме.

Сценарий:

1. Открыть RUTUBE.
2. Выполнить поиск видео.
3. Открыть первый видео-результат.
4. Проверить переход на страницу видео.
5. Сохранить скриншот и HTML страницы.

Сценарий запускается в GitHub Actions.

После выполнения сохраняются артефакты:

- `scenario2.png`
- `scenario2.html`
